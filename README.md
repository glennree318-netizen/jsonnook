# 🪺 JSONNook — Your JSON Workspace

Format, validate, convert, diff, and query JSON — all in one place.
**100% client-side. No backend. No uploads. Free forever.**

## ✨ Tools included

| Tool | Description |
|---|---|
| Formatter | Format, minify, validate, sort keys, escape/unescape |
| Tree View | Collapsible, searchable JSON tree |
| Converter | JSON ↔ YAML, JSON ↔ TOML, JSON ↔ CSV |
| Diff | Compare two JSONs with color-coded differences |
| JSON Path | Query JSON with `$.store.book[*].author` syntax |
| Schema | Auto-generate JSON Schema from any JSON |
| JWT Decoder | Decode header/payload, flag expired tokens |
| Base64 | UTF-8-safe encode/decode |
| Hash Generator | SHA-1/256/384/512 via Web Crypto |
| UUID Generator | Bulk-generate up to 100 v4 UUIDs |
| Timestamp | Unix ↔ date converter + live clock |
| Snippets | Save/load JSON snippets (localStorage) |

## 🔒 Privacy

Your data never leaves your browser. No server, no cookies.

The page loads a small cookieless analytics script (Umami) on the production
hostname only, to count visits. It sets no cookies, builds no profile, and never
sees your JSON, because all formatting, validation and querying happens locally.
Load the page once and use it offline and nothing is sent at all.

## 📲 PWA

JSONNook is installable and works offline (service worker + manifest included).

## 🚀 Run it

Just open `index.html` in a browser — or host it anywhere static
(GitHub Pages, Netlify, Vercel, Cloudflare Pages).
